# MyAI Chatbot

A simple Python GUI chatbot powered by Ollama and the Qwen 2.5 0.5B language model.

## Features
- Chat through a graphical interface.
- Generate AI responses locally using Ollama.
- Keep conversations on your computer when using the local model.

## Requirements
- Windows
- Python
- Ollama
- Qwen 2.5 0.5B model

## How to Run

1. Install Python and Ollama.
2. Open a terminal.
3. Download the model:

   `ollama pull qwen2.5:0.5b`

4. Make sure Ollama is running.
5. Run the chatbot:

   `python gui_chatbot.py`
